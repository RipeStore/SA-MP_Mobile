An iOS client for San Andreas Multiplayer. Native code, live server discovery, and a launcher built around how people actually play on an iPhone.

Features :
- Player counts, ping, gamemode and status pulled continuously. Filter, favourite, and join without leaving the launcher.
- Every on-screen control can be moved, resized or hidden. Save a layout once and it follows your account.
- Frame cap, draw distance, texture quality and memory ceiling configurations.
- Opus voice chat on its own channel, with per-player volume and push-to-talk that survives the app being backgrounded.
